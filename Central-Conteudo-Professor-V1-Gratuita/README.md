# Central de Conteúdo com IA para Professores — V1 Gratuita

![Versão 1 gratuita](versao-1-gratis-800x800.png)

A versão 1.0 é gratuita e pode ser usada sem cadastro, e-mail ou código de acesso.

Ela auxilia professores na criação de aulas, exercícios, slides e outros materiais pedagógicos com inteligência artificial.

## Download

[Baixar a Central de Conteúdo para Professores V1](Central-Conteudo-Professor-V1-Gratuita.zip)

## Antes de instalar

- Windows 10 ou 11;
- Docker Desktop instalado e aberto;
- para usar o Ollama, instale e abra o Ollama e deixe disponível o modelo de IA indicado no aplicativo.

## Como iniciar

1. Baixe o arquivo ZIP.
2. Clique com o botão direito e escolha **Extrair tudo**.
3. Abra a pasta extraída.
4. Execute `INICIAR.cmd`.

Não execute o iniciador diretamente de dentro do ZIP.

## Observação

A versão gratuita não inclui serviços, créditos ou chaves de provedores de inteligência artificial. Quando necessário, cada pessoa utiliza sua própria configuração de IA.

Projeto disponibilizado pelo canal [Café com Dados & Gatos](https://github.com/djeannie29/cafe_dados_e_gatos).
