## Sobre os testes / About the tests / Sobre las pruebas

No laboratório de **20/11/2026**, o freelm **0.5.2** foi testado no Ubuntu/WSL2. Houve respostas de modelos gratuitos, validação de chaves de Gemini, Groq e OpenRouter, e criação de uma página HTML com **Zoo Code** no VS Code usando a API local. Os logs mostraram modelos diferentes atendendo às chamadas; **não foi demonstrado failover decorrente de erro**.

In the November 20, 2026 lab, the tool worked with several providers and Zoo Code. **Error-triggered failover was not proven.**

En las pruebas del 20 de noviembre de 2026, la herramienta funcionó con varios proveedores y Zoo Code. **No se comprobó un failover provocado por error.**
