# How to Turn a TV Box into an AI Gateway — Part 1

**Café com Dados & Gatos | Video 01 documentation and commands**

In this guide, we use a **BTV BX** with an **Amlogic S905X** processor, **p212** board, **2 GB of RAM**, and **16 GB of storage** to run **Armbian Linux**, **XFCE Minimal**, **XRDP**, and **FreeLM**. The BTV hosts the gateway; AI responses are generated by external providers, not by a large model running inside the TV Box.

> **Compatibility warning:** TV boxes that look similar may use different boards, Wi-Fi chips, and controllers. Verify the hardware and test Linux from external media before considering installation to internal storage. Installing to eMMC may overwrite the original system and require device-specific recovery procedures.

## Prepare the USB drive — Windows

In balenaEtcher, select **Flash from file**, choose the specified `.img.gz` file, select the USB drive, and click **Flash**. The application can flash directly from the compressed image.

**Warning:** flashing erases the USB drive. After flashing, do not accept any Windows prompt asking you to format the Linux partitions.

For this board, inspect the boot partition for the `uEnv.txt` file and the p212 DTB entry:

```text
FDT=/dtb/amlogic/meson-gxl-s905x-p212.dtb
```

The exact location and format depend on the image you use. Do not mix boot files from different projects or copy an arbitrary `u-boot` file from another TV box.

## Check Linux and storage — BTV terminal

```bash
cat /etc/os-release
uname -m
uname -r
free -h
lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINTS
df -h
ip -br address
```

The `lsblk` command helps you check whether the root filesystem `/` is mounted on external media (such as `sda`) or internal storage (`mmcblk`, depending on the board).

## Test network connectivity — BTV terminal

```bash
ping -c 3 1.1.1.1
getent hosts github.com
```

## Install XFCE Minimal — BTV terminal

```bash
sudo apt update
sudo apt install -y --no-install-recommends xorg xfce4 xfce4-terminal lightdm lightdm-gtk-greeter dbus-x11
sudo systemctl enable lightdm
sudo reboot
```

After rebooting, check the graphical desktop, keyboard, mouse, and terminal.

## Find the BTV IP address and check SSH — BTV terminal

```bash
hostname -I
systemctl is-active ssh
```

If the SSH server is not installed or running:

```bash
sudo apt update
sudo apt install -y openssh-server
sudo systemctl enable --now ssh
```

## Connect to the BTV terminal — Windows PowerShell

Replace `teste` with your TV box's Linux username and `192.168.10.106` with the IP address shown by `hostname -I`.

```powershell
ssh teste@192.168.10.106
```

The following Linux commands run **on the BTV**, even when you type them through an SSH session. Do not run `apt` directly in PowerShell unless you are connected to the BTV through SSH.

## Install XRDP — BTV terminal

Run these commands as a regular Linux user with `sudo` permissions (for example, `teste`):

```bash
sudo apt update
sudo apt install -y xrdp xorgxrdp dbus-x11
printf 'startxfce4\n' > "$HOME/.xsession"
sudo systemctl enable --now xrdp
systemctl is-active xrdp
hostname -I
ss -lnt | grep ':3389'
```

## Connect from Windows — Remote Desktop

Press **Win + R**, type `mstsc`, enter the BTV IP address, and sign in using the **Linux** username and password. Select the **Xorg** session if that option appears.

The PC and BTV must be on the same local network. **Do not expose port 3389 to the public internet.** XRDP may start a separate graphical session from the one shown through HDMI.

## Basic tools — BTV terminal

```bash
sudo apt update
sudo apt install -y python3 python3-pip curl ca-certificates git
python3 --version
```

On a community-adapted TV box, do not upgrade the kernel or bootloader without checking board compatibility first.

## Install Node.js 22 with nvm — BTV terminal

FreeLM 0.5.2 requires Node.js 20 or newer. For this project we use **Node.js 22** through nvm, without installing global npm packages as `root`.

```bash
command -v curl
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.41.0/install.sh | bash
source ~/.bashrc
nvm install 22
nvm alias default 22
node --version
npm --version
which node
```

## Install and start FreeLM — BTV terminal

```bash
npm install -g freelm
freelm --help
freelm doctor
freelm serve
```

Keep this terminal window open. The server listens at **`http://127.0.0.1:4000/v1` on the BTV itself**.

## Test the server — another BTV terminal

```bash
curl -fsS http://127.0.0.1:4000/health
curl -fsS http://127.0.0.1:4000/v1/models
```

## Open the SSH tunnel — PowerShell on the Windows PC

With `freelm serve` running on the BTV, open **another** PowerShell window on the PC and run:

```powershell
ssh -N -L 4400:127.0.0.1:4000 teste@192.168.10.106
```

Replace the username and IP address with those of your TV box. Keep the tunnel window open: it forwards **port 4400 on the PC** to **port 4000 on the BTV** without exposing the server to the internet.

## Test the tunnel — second PowerShell window on the PC

```powershell
curl.exe -fsS http://127.0.0.1:4400/health
```

## Configure the AI client in VS Code — Windows PC

In a client or extension supporting OpenAI-compatible APIs, use the following values wherever the corresponding settings are available:

| Setting | Value |
| --- | --- |
| API type | OpenAI Compatible |
| Base URL | `http://127.0.0.1:4400/v1` |
| API Key (local test value) | `freelm` |
| Model | `auto` |

Ask a short question to verify communication between VS Code, the SSH tunnel, and FreeLM. Free-model availability depends on the providers and their quotas.

## Stop the test

Press **Ctrl+C** in the tunnel's PowerShell window and in the BTV terminal where `freelm serve` is running.

## Issues encountered and fixes

**Node.js 18 was incompatible with FreeLM:** the initial Debian package version was lower than the tool's requirement. We switched to Node.js 22 through nvm.

**`EACCES` error with `npm install -g`:** the regular user lacked permission to install global packages in the system directory. With nvm, Node.js and global npm packages reside under the user's own directory, so `sudo` is not needed.
